# Участие в разработке

1. Создавайте отдельную ветку для изменения.
2. Используйте Godot 4.x и GDScript.
3. Все видимые игроку строки пишите на русском языке.
4. Не добавляйте ассеты без подтверждённой лицензии.
5. Проверяйте запуск проекта в Godot перед Pull Request.
6. Описывайте проверенные сценарии и известные ограничения.
