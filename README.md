# ПОСЛЕДНИЙ РУБЕЖ: ОСТРОВ

3D survival от первого лица для Android и ПК. Атмосфера заброшенного острова: выцветшее дерево, потёртый металл, камень, хвойный лес и старые поселения. Визуальный стиль — суровый реалистичный survival с приглушённой природной палитрой.

## Прототип 0.3
- 3D-мир от первого лица.
- Автоматическая поддержка вертикальной и горизонтальной ориентации Android.
- Адаптивный HUD: панели ресурсов и кнопки перестраиваются под формат экрана.
- Процедурные шумовые текстуры для земли, стен, дерева, листвы и камней.
- Заброшенные дома и склад, лес, камни и ящики.
- Сбор дерева и камня, обыск ящиков.
- Здоровье, голод, жажда и ресурсы.
- Строительство деревянных стен.

## Управление
WASD — движение; Shift — бег; Space — прыжок; мышь — обзор; E — сбор; Tab — рюкзак; B — строительство; ЛКМ — поставить стену. На сенсорном экране свайп слева управляет движением, свайп справа — обзором; кнопки действий находятся справа.

## Запуск
Откройте `project.godot` в Godot 4.3. Android экспортируется через GitHub Actions.

Это ранний прототип. Полный набор механик Rust ещё не реализован; визуальные материалы пока процедурные и будут заменяться полноценными PBR-текстурами по мере разработки.
