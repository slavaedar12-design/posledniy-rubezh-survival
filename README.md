# ПОСЛЕДНИЙ РУБЕЖ: ЗАРАЖЕНИЕ

Мобильная 2D survival-RPG о выживании в разрушенном Чернограде. Проект создан на Godot 4.x, интерфейс и документация — на русском языке.

## Состояние проекта

Это ранний играбельный прототип 0.1.0, а не завершённая игра. Уже реализованы перемещение, ближняя атака, заражённые, подбор припасов, инвентарь, параметры выживания, опыт, уровни и локальное сохранение. Полноценные кампания, крафтинг, строительство базы, карта районов, NPC, звук и релизная Android-сборка пока не реализованы.

## Запуск на ПК

1. Установите Godot Engine 4.3 или новее.
2. Откройте Godot Project Manager.
3. Нажмите «Импорт» и выберите файл `project.godot`.
4. Запустите проект клавишей F6/F5.

## Android

1. Установите Android SDK и совместимый JDK.
2. В Godot установите Export Templates.
3. Укажите пути к SDK/JDK в настройках редактора.
4. Добавьте пресет Android в меню «Проект → Экспорт».
5. Экспортируйте APK для тестирования или AAB для Google Play.

Файлы подписи и keystore не включаются. Не публикуйте приватные ключи и пароли.

## Управление

| Действие | Клавиатура | Сенсорный экран |
|---|---|---|
| Движение | WASD / стрелки | Левая половина экрана |
| Атака | Пробел | «УДАР» |
| Обыск | E | «ОБЫСКАТЬ» |
| Инвентарь | I | «РЮКЗАК» |
| Сохранить | — | «СОХРАНИТЬ» |

## Структура

- `scenes/` — сцены Godot.
- `scripts/player/` — персонаж.
- `scripts/enemies/` — заражённые.
- `scripts/save_system.gd` — сохранение.
- `docs/` — документация.
- `.github/workflows/` — автоматическая проверка.

## Проверки

GitHub Actions запускает headless-импорт Godot и короткую проверку главной сцены при каждом push и pull request. Результаты доступны во вкладке Actions.
