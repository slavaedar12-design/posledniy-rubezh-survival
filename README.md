# УКРАДИ ЯЙЦО — 3D PET ISLAND

Яркая 3D-игра для Android на Godot 4.3, вдохновлённая жанром egg-stealing / pet tycoon. Это самостоятельный проект с оригинальными процедурными моделями и материалами, а не копия исходных ассетов Roblox.

## Игровой цикл
- Исследуй красочный остров и четыре тематические зоны.
- Подойди к яйцу, забери его и доставь на свою базу.
- Убегай от стража, который преследует игрока с добычей.
- Дождись вылупления и получи питомца.
- Питомцы приносят монеты каждую секунду.
- Покупай улучшения скорости, чтобы открывать более редкие яйца.

## Визуальный стиль
Стилизованная low-poly 3D-графика, яркая палитра, плавающие яйца с подсветкой, вода, деревья, декоративные зоны, мультяшный персонаж, эффекты вылупления и анимация питомцев. HUD и кнопки адаптируются под вертикальный и горизонтальный экран.

## Управление
- ПК: WASD — движение, мышь — камера, E / Space — взять яйцо.
- Android: свайп слева — движение, свайп справа — обзор, экранные кнопки — взять яйцо и улучшить скорость.

## Сборка Android
Проект собирается через GitHub Actions в APK ARM64. Открой вкладку Actions в репозитории и скачай артефакт `posledniy-rubezh-android-debug` после успешной сборки.

## Запуск
Открой `project.godot` в Godot 4.3.
